# Навыки AIRL для группы Orzu Medical

Навыки для Claude Code, которые ведут вас по проекту шаг за шагом. Каждый навык сам задаёт вопросы, отвечать можно одной буквой.

| Навык | Когда запускать | Что получите |
|---|---|---|
| `/airl-context` | Один раз в начале | Свой приватный репозиторий на GitHub и файл `CLAUDE.md`: память проекта, Claude помнит его в каждом новом чате |
| `/airl-code-review` | Перед передачей проекта разработчику | Проверка кода простым языком и отчёт `REVIEW.md`: ключи и пароли не в коде, важные ошибки исправлены |
| `/airl-dwh` | Когда понятно, какие данные нужны | `DWH.md`: какие данные нужны проекту и откуда их брать |

## Установка и обновление

Откройте Claude Code и напишите:

> Установи навыки из https://github.com/aza9908/orzu-medical-skills: скачай репозиторий и скопируй папки из skills в ~/.claude/skills с заменой. Потом скажи, что перезапустить.

Или вручную: скачайте репозиторий (Code, Download ZIP), распакуйте и запустите

- macOS: `bash install.sh`
- Windows: `powershell -ExecutionPolicy Bypass -File install.ps1`

Перезапустите Claude Code и наберите `/`: в списке появятся навыки.

## Где хранится ваш проект

У каждого участника свой приватный репозиторий на GitHub. Доступ к нему вы даёте сами: разработчику клиники и тренеру AIRL (Settings, Collaborators, Add people).

## Правила

- Только выдуманные данные пациентов.
- Ключи и пароли не загружаем на GitHub.
- Одна задача, один чат. Память проекта хранится в `CLAUDE.md`.

Навыки взяты из [aza9908/airl-skills](https://github.com/aza9908/airl-skills).
