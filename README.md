# Навыки AIRL для группы Orzu Medical

Два навыка для домашнего задания после урока 2.

| Навык | Что делает |
|---|---|
| `/airl-dwh` | Задаёт вопросы о данных вашего проекта и пишет `DWH.md`: какие таблицы нужны и как они связаны. По этому файлу разработчик соберёт общую базу клиники. |
| `/orzu-status` | Раз в неделю спрашивает, что сделано и где вы застряли, ставит стадию проекта и отправляет всё на GitHub. Тренер видит сводку по всем. |

## Установка

Проще всего попросить Claude Code. Откройте его и напишите:

> Установи навыки из репозитория https://github.com/aza9908/orzu-medical-skills: скачай его и скопируй папки из skills в папку навыков ~/.claude/skills. Потом скажи, что перезапустить.

Или вручную: скачайте репозиторий (Code → Download ZIP), распакуйте и запустите

- macOS: `bash install.sh`
- Windows: `powershell -ExecutionPolicy Bypass -File install.ps1`

Перезапустите Claude Code.

## Домашка

1. Откройте свой проект из репозитория `orzu-medical-projects` в Claude Code.
2. Наберите `/airl-dwh` и отвечайте на вопросы. В конце появится `DWH.md` в папке вашего проекта.
3. Наберите `/orzu-status`. Навык запишет стадию и отправит изменения на GitHub.
4. Дальше `/orzu-status` каждую пятницу.

Данные пациентов только выдуманные. Ключи и пароли на GitHub не загружаем.

## Для тренера

В корне `orzu-medical-projects`: `/orzu-status отчёт` покажет таблицу по всем проектам: стадия, есть ли `DWH.md`, кто застрял.

Навык `airl-dwh` взят из [aza9908/airl-skills](https://github.com/aza9908/airl-skills).
